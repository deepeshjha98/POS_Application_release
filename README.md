# दुकान POS — अपडेट

ये repo सिर्फ़ **बने हुए app** के लिए है. असली code निजी repo में है.

Windows वाला app इसी जगह से अपना नया रूप उठाता है — app के ऊपर दाएँ
कोने में `⟳ अपडेट` बटन दबाने पर.

## app के तीन हिस्से

| हिस्सा | क्या है | कैसे बदलता है |
|---|---|---|
| **पर्दा** (`web/`) | जो दिखता है — सारे बटन, सूची, कीबोर्ड | अपडेट बटन से |
| **दिमाग़** (`brain/`) | असली हिसाब-किताब, डेटाबेस, जाँच के नियम | अपडेट बटन से |
| **खोल** (`install/`) | Electron ख़ुद — कभी-कभार ही बदलता है | अपडेट बटन से (वो ख़ुद setup चला लेता है) |

यानी अब **तीनों इसी एक बटन से** बदलते हैं. setup फ़ाइल हाथ से चलाने की
ज़रूरत सिर्फ़ पहली बार पड़ती है.

## इसमें क्या है

| फ़ाइल | क्या है |
|---|---|
| `version.json` | अभी कौन-सा रूप चल रहा है — app यही सबसे पहले पढ़ता है |
| `web/index.html` | पूरा पर्दा, एक ही फ़ाइल में (~310 KB) |
| `brain/main.cjs` | app का दिमाग़ |
| `brain/preload.cjs` | पर्दे और दिमाग़ के बीच की इकलौती खिड़की |
| `install/DukanPOS-Setup.cmd` | app बिठाने वाली फ़ाइल |
| `install/dukan-app.zip` | उसी के साथ की दूसरी फ़ाइल |
| `*.sha256` | हर फ़ाइल का जोड़ — पूरी उतरी या नहीं, ये जाँचने के लिए |

## पहली बार app बिठाना

1. `install/` से दोनों फ़ाइलें उतार लीजिए — `DukanPOS-Setup.cmd` और `dukan-app.zip`
2. दोनों को **एक ही फ़ोल्डर** में रखिए
3. `DukanPOS-Setup.cmd` पर double-click
4. Windows चेतावनी दे तो "More info" → "Run anyway"

Electron (~110 MB) अपने आप उतरेगा, सिर्फ़ पहली बार. Desktop पर शॉर्टकट बन जाएगा.

इसके बाद ये फ़ाइलें दोबारा हाथ से चलाने की ज़रूरत नहीं — ज़रूरत पड़ी तो
app ख़ुद इन्हें यहीं से उतार कर ख़ुद चला लेगा.

## अपडेट कैसे लगता है

हर फ़ाइल पूरी उतरने **और** उसका sha256 मिलने के बाद ही वो पुरानी की जगह
लेती है. बीच में इंटरनेट कट जाए तो कुछ नहीं बदलता — app पुराने रूप में
चलता रहता है. आधा-अधूरा अपडेट कभी नहीं लगेगा.

दिमाग़ कभी उसी जगह नहीं बदला जाता जहाँ से वो चल रहा है. नया दिमाग़ अलग
फ़ोल्डर में उतरता है, और अगली बार app उसे चला कर देखता है. वो चल पड़े तभी
"पक्का" होता है — **न चले तो app अपने आप पुराने भरोसेमंद दिमाग़ पर लौट आता
है.** दुकान किसी हाल में रुकनी नहीं चाहिए, इसलिए यही तरीक़ा है.

आपका सामान, श्रेणियाँ और सारा हिसाब आपकी अपनी मशीन पर रहता है
(`%APPDATA%\dukan-pos\pos.db`) — अपडेट से उसे कुछ नहीं होता.
