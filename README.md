# दुकान POS — अपडेट

ये repo सिर्फ़ **बने हुए app** के लिए है. असली code निजी repo में है.

Windows वाला app इसी जगह से अपना नया रूप उठाता है — app के ऊपर दाएँ
कोने में `⟳ अपडेट` बटन दबाने पर.

## इसमें क्या है

| फ़ाइल | क्या है |
|---|---|
| `version.json` | अभी कौन-सा रूप चल रहा है — app यही सबसे पहले पढ़ता है |
| `web/index.html` | पूरा पर्दा, एक ही फ़ाइल में (~300 KB) |
| `web/index.html.sha256` | उसका जोड़ — पूरी उतरी या नहीं, ये जाँचने के लिए |
| `setup/` | पहली बार app बिठाने वाली दो फ़ाइलें |

## पहली बार app बिठाना

1. `setup/` से दोनों फ़ाइलें उतार लीजिए — `DukanPOS-Setup.cmd` और `dukan-app.zip`
2. दोनों को **एक ही फ़ोल्डर** में रखिए
3. `DukanPOS-Setup.cmd` पर double-click
4. Windows चेतावनी दे तो "More info" → "Run anyway"

Electron (~110 MB) अपने आप उतरेगा, सिर्फ़ पहली बार. Desktop पर शॉर्टकट बन जाएगा.

## अपडेट कैसे लगता है

अपडेट बटन सिर्फ़ `web/index.html` उतारता है — ~300 KB, दो-तीन सेकंड.
पूरा app दोबारा नहीं उतरता.

फ़ाइल पूरी उतरने **और** उसका sha256 मिलने के बाद ही वो पुरानी की जगह लेती है.
बीच में इंटरनेट कट जाए तो कुछ नहीं बदलता — app पुराने रूप में चलता रहता है.
आधा-अधूरा अपडेट कभी नहीं लगेगा.

आपका सामान, श्रेणियाँ और सारा हिसाब आपकी अपनी मशीन पर रहता है
(`%APPDATA%\dukan-pos\pos.db`) — अपडेट से उसे कुछ नहीं होता.
